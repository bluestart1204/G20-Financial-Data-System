## 🎯 模型分析框架

### 8个核心因子

| 因子 | 权重 | 相关性 | 说明 |
|------|------|--------|------|
| 美元指数 | -0.35 | 负 | 美元强弱与金价反向 |
| 通货膨胀率 | 0.25 | 正 | 通胀推高避险需求 |
| 实际利率 | -0.20 | 负 | 利率上升增加持金成本 |
| 地缘政治风险 | 0.15 | 正 | 风险增加推高金价 |
| 央行购金 | 0.12 | 正 | 官方储备需求 |
| 市场情绪 | 0.08 | 正 | 投资者信心影响 |
| 原油价格 | 0.10 | 正 | 大宗商品联动 |
| 股市表现 | -0.05 | 负 | 资产配置转移 |

### 5个触发器

| 触发器 | 权重 | 激活年份 | 影响 |
|--------|------|----------|------|
| 金融危机 | 0.40 | 2008-2009 | 极大推高金价 |
| 量化宽松 | 0.30 | 2009-2014 | 货币宽松利好黄金 |
| 疫情冲击 | 0.35 | 2020-2021 | 避险需求激增 |
| 贸易战 | 0.15 | 2018-2019 | 增加不确定性 |
| 主权债务危机 | 0.25 | 2010-2012 | 欧债危机影响 |

## 📈 关键发现

### 历史表现（2000-2023）

- **最大涨幅**: 2007年 (+31.4%)
  - 主因：金融危机前夕，市场不确定性增加
  
- **最大跌幅**: 2013年 (-28.3%)
  - 主因：量化宽松退出预期，美元走强

- **平均年涨幅**: 约 8.9%
  - 黄金长期保值特性明显

### 因子贡献模式

1. **美元指数**: 最重要的影响因素（权重-0.35）
   - 美元强弱直接影响金价
   
2. **实际利率**: 持金机会成本的关键
   - 低利率环境利好黄金
   
3. **事件驱动**: 触发器在特殊时期作用显著
   - 2008-2009、2020-2021为典型例子

## 🚀 使用方法

### 快速生成报告

```bash
cd src/analysis
python export_analysis.py
```

### 在代码中使用

```python
from src.analysis.gold_price_model import GoldPricePredictionModel

# 创建模型
model = GoldPricePredictionModel()

# 分析单年
result = model.analyze_year(2020)
print(f"2020年预测涨跌: {result['predicted_return']:.1f}%")
print(f"2020年实际涨跌: {result['actual_return']:.1f}%")

# 批量分析
results = model.get_all_years_analysis(2000, 2023)
```

### 运行测试

```bash
pytest tests/test_gold_price_analysis.py -v
```
