# 黄金价格预测模型 V7.0 使用文档

## 📋 概述

**增强版黄金价格预测模型 V7.0** 是一个集成因子贡献追溯系统的完整金价预测模型。基于 2000-2023 年历史数据，通过 15 个核心因子、18 个情景触发器和 5 层传导链，实现精准的金价预测和详细的因子分析。

### 核心特性

- ✅ **15因子多维度分析** - 覆盖需求、供给、金融、技术、情绪五大维度
- ✅ **18触发器情景机制** - 识别重大市场事件的影响
- ✅ **权重智能优化** - 基于历史数据自动优化因子权重
- ✅ **5层传导链追溯** - 完整展示从原始数据到最终影响的全过程 ⭐ NEW
- ✅ **交互式查询系统** - 灵活查询任意因子、任意年份 ⭐ NEW
- ✅ **数据导出功能** - 支持 CSV/Excel 格式导出

## 📖 功能详解

### 1. 因子追溯 (trace_factor) ⭐ 核心功能

追溯单个因子在特定年份的完整计算过程，展示 5 层传导链。

#### 使用方法

```python
# 查询2023年央行购金的影响
model.trace_factor('央行购金', 2023)

# 也可以使用英文名
model.trace_factor('central_bank', 2023)

# 不显示详细输出，只返回结果
result = model.trace_factor('央行购金', 2023, verbose=False)
```

## 💡 使用示例

### 示例 1: 研究央行购金的影响

```python
# 创建模型
model = EnhancedGoldPredictionModelV7()
model.run_complete_analysis()

# 查看2023年央行购金的详细影响
model.trace_factor('央行购金', 2023)

# 对比过去4年的趋势
model.compare_factor('央行购金', [2020, 2021, 2022, 2023])
```

### 示例 2: 分析某一年的所有驱动因素

```python
# 分析2020年（新冠疫情年）
df = model.analyze_year(2020, export_csv=True)

# 查看最重要的5个因子
print(df.head())
```

### 示例 3: 批量导出多年数据

```python
# 导出2020-2023年的分析结果
for year in range(2020, 2024):
    model.analyze_year(year, export_csv=True)
    print(f"✓ 已导出 {year} 年数据")
```

### 示例 4: 验证模型准确性

```python
# 验证最近5年的计算
for year in range(2019, 2024):
    result = model.validate_calculation(year)
    if result['valid']:
        print(f"✓ {year} 年验证通过")
    else:
        print(f"✗ {year} 年验证失败，误差 {result['error_percentage']:.1f}%")
```

## 🔧 高级用法

### 自定义权重

```python
# 使用自定义权重
model = EnhancedGoldPredictionModelV7()
model.setup_historical_data_with_new_factors()
model.define_scenario_triggers()
```

## 📝 注意事项
